# Claude Skills

Skills for Claude by Sachin Raj.

| Skill | What it does |
|---|---|
| [career-portfolio](career-portfolio/) | Turns your resume, headshot and LinkedIn URL into an interactive, animated portfolio website you can share on LinkedIn. |

## Installing a skill

1. Download this repository (green **Code** button → **Download ZIP**) and unzip it.
2. Zip the skill's folder on its own (for example, the `career-portfolio` folder).
3. **Claude (web or desktop):** upload that zip in the Skills section of Claude's settings.
   **Claude Code:** copy the skill folder into `~/.claude/skills/`.

Each skill's own README explains how to use it.
